# anti-slop (vendored)

Oxlint JS plugin from https://github.com/dmmulroy/anti-slop (MIT, see LICENSE), copied from
commit `13909c9` without tests and without the Effect rules. There is no npm package: to
update, copy `src/` again and keep `oxlint` and `@oxlint/plugins` on the same exact version.

The rules this repo enables are listed in `.oxlintrc.json`.
